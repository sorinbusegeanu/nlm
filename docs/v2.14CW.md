# V2.14CW — Class-Weighted SFT

V2.14CW reuses the V2.14 Parquet artifact and profile without copying or changing any row. Its training recipe applies weighted cross-entropy to the true training label: weight `2.0` for `claude-fable-5`, `glm-5.3` and `gemini-3.7-flash`; weight `1.0` for every other label. The original class distribution and training sampler are unchanged. Validation loss and metrics are unweighted.

The training pipeline resolves `v2.14CW` to `data/processed/dataset_v2.14.parquet` and reads its weights from `configs/datasets.yaml`. The selected dataset ID remains `v2.14CW` in experiment metadata. Encoder and LoRA/QLoRA SFT classifiers support the recipe. Other classifier types reject class weights rather than silently ignoring them.

Example command:

```bash
python -m src.pipeline models train \
  --model ultrabert380 \
  --dataset v2.14CW \
  --validation-dataset v0 \
  --accept-config-defaults
```

This documents a selectable configuration only. No training run is started by dataset registration.
