# E43 — E33-F plus E41

## Status

Registered before packaging in the ensemble catalog. Kaggle version 7 completed and submission **58967216** was accepted; Kaggle has not returned its score yet (`PENDING`).

## Method

E43 preserves E33-F's Trust List 2 v037 E31 40-checkpoint roster, frozen family-max router, and candidate-correctness adjustment. It runs the enhanced E38 SVC and E39 tokenizer CatBoost on each competition response and averages their canonical 18-label probabilities into E41.

The E33-F adjusted score row is clamped at zero for unsupported labels and normalized to sum to one. E43 uses a fixed 50/50 mean of that normalized vector and E41 probabilities. No weights are selected on V0 or V0-EXT. The notebook writes only submission.parquet, in exact test ID order; grouping and Hungarian assignment are not part of this experiment.

## Deployment assets and validation

The shared dataset is zodrak/e38-e39-feature-members-v001. It contains the fitted E38 SVC bundle, the E39 CatBoost model, its tokenizer assets, the feature implementation, and offline tiktoken encoding caches. Runtime performs asset hash checks and E38/E39 probability smoke tests before the dual-GPU checkpoint workers start.

E43 reuses the E31/E33-F checkpoint and deployment datasets. Version 7 passed local and remote preflight, runtime checks, dual-GPU checkpoint inference, and output validation. It completed in 892 seconds end to end; E38/E39 inference took 13.8 seconds.
