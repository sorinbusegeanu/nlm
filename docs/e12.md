A single shared logistic classifier scores candidate pairs using antisymmetric per-checkpoint differences and distinct-family agreement. Swapping the candidates reverses the predicted probability. Each pair in the fitting candidate set contributes when its true label is one of the two candidates. Precision and recall use one positive and one negative pseudocount. Directional confusion uses one pseudocount for each of the 18 predicted labels. The model uses scale-only standardization, no intercept, and an inner three-fold search over C = 0.01, 0.1, 1 and 10 by pooled pairwise log loss.
