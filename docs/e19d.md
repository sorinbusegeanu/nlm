## E19-D protocol and details

Model: `google/embeddinggemma-2` is used for grouping embeddings; reconstruction model: `Qwen/Qwen3.5-4B` at revision `851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a`. Reconstruction used batch size 20 with dynamic batch splitting on CUDA OOM. Runtime: Transformers 5.19.0, Torch 2.13.0+cu130 (CUDA 13.0), GPU `NVIDIA GeForce RTX 5070 Ti`, FLA 0.6.0.

All 2699 V0 rows were held out exactly once under E19-B's saved five prompt-group folds. E19-D's aggregate pairwise precision is 100.00% and recall is 92.99%. The all-V0 fitted clustering is diagnostic only and is not included in this comparison.

Detailed fold metrics, all-V0 diagnostic, B-cubed metrics, group-size distributions, selected thresholds, and diagnostic examples are in `artifacts/analysis/e19d/`. E19-B baseline values are loaded from its saved OOF metrics. No base classifiers were trained.

## Method and rerun commands

Qwen3.5-2B reconstructs each response independently with greedy deterministic generation and a resumable response-hash/model-revision/prompt-version cache. Grouping combines E16 word/character lexical similarities on reconstructed prompts and original responses with frozen EmbeddingGemma2 semantic similarity, topic overlap, distinctive-detail/entity/number overlap, and constraint overlap. A regularized logistic pair scorer supplies edge probabilities; complete-link agglomeration rejects weak transitive bridges and caps clusters at 18.

Each saved E13-B outer fold remains untouched for final scoring. Within its training partition, four prompt-group inner folds select the logistic regularization and threshold by mean pairwise F1, then precision. The full-V0 grouping is a separately marked diagnostic.

Run with `/home/zodrak/cuda13.x/bin/python -m src.e19d_reconstruct --limit 100`, then `/home/zodrak/cuda13.x/bin/python -m src.e19d_reconstruct`, then `/home/zodrak/cuda13.x/bin/python -m src.e19d_evaluate`. For new unlabeled rows use `reconstruct_rows` with separate cache/output paths and `predict_groups` with the saved e19d_grouper.joblib.
