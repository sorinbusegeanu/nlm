# V2.14 dataset

`dataset_v2.14.parquet` contains **231,336 responses**:

- 223,840 rows from the Open Pool V14 main parquet.
- 7,496 B2M responses whose normalized text does not already occur in V14.

Deduplication uses Unicode NFKC normalization, case folding, and collapsed whitespace; punctuation is preserved. B2M rows already present in V14 were not duplicated, and the shared response texts had consistent model labels. The B2M-only additions use the existing normalized B2M artifact so source, prompt, route, provider and model-version metadata remain attached.

No quality filtering, language filtering, class balancing, or validation split was performed. Of the B2M additions, 891 are labelled `gemini-3.7-flash`; the B2M provenance marks all 891 `g37_rule=quarantine` and `model_version=n/s`. They remain included as requested, with that attribution evidence preserved. All 18 model labels remain, with natural class counts. The V14 `gemini37_unverified.parquet` sidecar is excluded; unique rows from the B2M main dataset are included as requested, with their B2M attribution/provenance retained.

The dataset profile records input hashes and class/source counts at [`dataset_profile_v2.14.json`](../data/processed/dataset_profile_v2.14.json). It is marked external-only. A loader-only check created [`splits_v2.14_full_v0.parquet`](../data/processed/splits_v2.14_full_v0.parquet) and [`dataset_profile_v2.14_full_v0.json`](../data/processed/dataset_profile_v2.14_full_v0.json): all 231,336 external rows train, and all 2,699 V0 rows validate.
