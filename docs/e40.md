## V0-EXT overlap caveat

V2.14 contains 3734 of 4,000 V0-EXT rows (93.35%) by both response ID and NFKC/casefold/whitespace-normalized text. V0 has zero response-ID and normalized-text overlap. Full V0-EXT scores are therefore contaminated and should not be interpreted as unseen-response generalization. The remaining subset has only 15 represented labels.

## Features and configuration

E40 adds 20 features from cl100k_base unigram and bigram statistics fitted only on V2.14 training texts. Smoothed unigram and interpolated conditional bigram probabilities produce surprisal, conditional entropy, probability-rank and sequential-surprisal features. The fitted counts are saved beside `model.cbm` and loaded by the existing CatBoost prediction factory. Offline model inference returned finite probabilities over all 18 labels. E40 reuses the exact CatBoost baseline trained for E39.

Configuration: `configs/features/catboost_stylometry_e40.yaml`; CatBoost configuration: `configs/models/catboost_stylometry_e40.yaml`; runtime thread cap: four.

Reference: [competitor feature implementation](https://huggingface.co/datasets/yauwes/name-that-llm-sota-artifacts/blob/main/src/stage1_2_features.py).

Artifacts: `artifacts/analysis/e40/`. Consolidated comparison and validation overlap audit: `artifacts/analysis/e38_e40/comparison.json` and `validation_overlap_audit.json`.
