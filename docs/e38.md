## V0-EXT overlap caveat

V2.14 contains 3734 of 4,000 V0-EXT rows (93.35%) by both response ID and NFKC/casefold/whitespace-normalized text. V0 has zero response-ID and normalized-text overlap. Full V0-EXT scores are therefore contaminated and should not be interpreted as unseen-response generalization. The remaining subset has only 15 represented labels.

## Representation and configuration

The enhanced SVC retains the original character and word TF-IDF views and adds character word-boundary n-grams, word-plus-punctuation n-grams, case-preserving character-shape n-grams that retain full word lengths, and Stamatatos distorted-text n-grams. Reference weights: 1.0 (character), 0.85 (char_wb), 1.15 (word+punctuation), 0.55 (shape), 0.75 (distortion); preserved original word view weight 1.0. Vocabulary caps, document-frequency limits and n-gram ranges are configured in `configs/features/e38_extended_svc.yaml`. Both SVCs use C=0.5, balanced class weights and three-fold sigmoid calibration.

Recorded total fit/scoring time: 690.1s baseline and 1651.8s enhanced; the enhanced SVC training fit was 1621.1s. The final enhanced model uses float32 for the four new reference views and the character view; the preserved legacy word view retains its original float64 default. The initial run that accidentally passed the YAML dtype as a string (causing scikit-learn to convert to float64) is preserved in `artifacts/analysis/e38/initial_float64/`; the reported final metrics use the corrected float32 run. Model bundles, predictions and separate feature caches are in `artifacts/analysis/e38/`.

Reference: [competitor feature pipeline](https://huggingface.co/datasets/yauwes/name-that-llm-sota-artifacts/blob/main/src/stage3_4_5_pipeline.py) and [feature helpers](https://huggingface.co/datasets/yauwes/name-that-llm-sota-artifacts/blob/main/src/stage1_2_features.py).
