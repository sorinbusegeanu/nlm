# E31 — E13-B Expansion from 17 to 40 Checkpoints

This is the canonical E31 checkpoint-expansion report referenced by the experiment catalogue. It is separate from the completed [E31-Confusion three-model diagnosis](e31_confusion.md).

## Scope and baseline reconciliation

E31 uses the current corrected E30-B manifest as the fixed baseline. The manifest's actual roster contains **17 checkpoints**, despite the earlier description of E30 as a 20-checkpoint deployment. E31 targets **40 checkpoints total**, so it selects **23 additions**. Adding 20 would produce 37 total and would not meet the 40-checkpoint target. The active process is running the 40-total/23-addition configuration. E30 files and artifacts are not changed by E31.

The candidate pool is the 70 available Trust List 2 v037 checkpoints outside the E30 roster. The 17 shared baseline probability-cache hashes are checked against the E30 manifest before selection. All V0 rows, canonical labels and response IDs follow the E13-B conventions.

## Selection and evaluation protocol

For each of the five saved E13-B prompt-group outer folds, greedy selection begins with the 17-member baseline. Each candidate addition is evaluated by refitting the E13-B CatBoost router through four prompt-group-disjoint inner folds and comparing inner OOF predictions. Balanced accuracy is primary; paired net correct predictions, introduced errors and checkpoint ID resolve ties. The process evaluates all 23 additions, even when an addition has a negative marginal score.

The fixed 40-member roster is formed by fold consensus: selection frequency, mean selected rank, marginal balanced-accuracy gain, and checkpoint ID. Every candidate evaluation records BA, corrections, introduced errors and net correct predictions. The outer held-out predictions are generated separately for each fold-local roster size from 17 through 40; these cross-fitted results determine the best roster size from 20 through 40.

The final fixed-roster replay compares E30-B's saved 17-member deployment against E31's 40-member router on identical V0 rows and 50 `v0_group` scenarios. It also applies the same frozen E19-F-A and E19-F-C groupers followed by Hungarian assignment. Grouping quality and group-size distributions are measured against prompt IDs for diagnosis only; prompt IDs and labels do not enter grouping inference.

V0 has historical checkpoint-selection exposure. Outer-fold scores are prompt-group held-out estimates within that development set. The fixed-roster router and its reliability statistics are fit using V0 training examples, so its full-V0 replay is an in-sample deployment diagnostic, not an independent test result.

## Fixed-roster comparison on the same 50 `v0_group` scenarios

All four roster sizes were evaluated on the same 50 scenarios (500 responses in each). For each checkpoint count, one fixed roster and its deployment router generated a single aligned full-V0 score matrix; the independent prediction and all three Hungarian variants use that same matrix. E19-F-A, E19-F-C and E19-D groups were freshly reconstructed separately within each scenario using their frozen grouping implementations. The values below are the arithmetic mean of the 50 scenario balanced accuracies.

| Checkpoints | Independent | E19-F-A | E19-F-C | E19-D |
|---:|---:|---:|---:|---:|
| 15 | 65.2997% | 68.7756% | 68.4790% | 72.2044% |
| 17 | 66.8074% | 69.9686% | 69.7224% | 73.3844% |
| 20 | 65.7696% | 69.3777% | 69.2405% | 72.8760% |
| 40 | 68.2834% | 71.4179% | 71.3933% | 74.6671% |

The 15- and 17-checkpoint outputs reproduce their saved deployment predictions; the 40-checkpoint output reproduces the saved E31 full-V0 replay. The historical 20-member roster had no saved deployment router, so its router was fit from cached checkpoint probabilities using the same four-fold prompt-group OOF deployment-router procedure as E30/E31. Full-V0 reliability statistics were used for deployment feature construction.

These are in-sample robustness diagnostics: the scenarios reuse V0 rows, and the fixed deployment routers and reliability statistics were fit using V0-derived records. The 16 measurements, scenario-level predictions, score matrices, rosters, router hashes and provenance are saved under `artifacts/analysis/e31/roster_scenario_evaluation/` (`results.json`, `scenario_predictions.parquet`, `predictions_and_scores.npz`, and `router_20.json`).
