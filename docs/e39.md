## V0-EXT overlap caveat

V2.14 contains 3734 of 4,000 V0-EXT rows (93.35%) by both response ID and NFKC/casefold/whitespace-normalized text. V0 has zero response-ID and normalized-text overlap. Full V0-EXT scores are therefore contaminated and should not be interpreted as unseen-response generalization. The remaining subset has only 15 represented labels.

## Features and configuration

The 16 added numeric features use cl100k_base, o200k_base, Qwen3-Embedding-0.6B and GPT-2 tokenizers: tokens per word and character; pairwise tokenizer ratios/differences; and UTF-8 byte density. The enhanced classifier has 51 features. E39 and E40 share the same CatBoost baseline trained once. Tokenizer assets and SHA-256 hashes are saved beside the model. Offline inference from the E39 checkpoint was verified to return a finite 18-label probability vector summing to 1.

Configuration: `configs/features/catboost_stylometry_e39.yaml`; CatBoost configuration: `configs/models/catboost_stylometry_e39.yaml`; runtime thread cap: four.

Reference: [competitor feature implementation](https://huggingface.co/datasets/yauwes/name-that-llm-sota-artifacts/blob/main/src/stage1_2_features.py).

Artifacts: `artifacts/analysis/e39/`. Consolidated comparison and validation overlap audit: `artifacts/analysis/e38_e40/comparison.json` and `validation_overlap_audit.json`.
