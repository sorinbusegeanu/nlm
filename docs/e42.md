# E42 — E13-B plus E41

## Status

Registered before packaging in the ensemble catalog. Kaggle version 7 completed and submission **58967537** was accepted; Kaggle has not returned its score yet (`PENDING`).

## Method

E42 preserves E13-B's Trust List 2 v037 15-checkpoint roster, reliability router, and family-max routing. It runs the enhanced E38 SVC and E39 tokenizer CatBoost on each competition response, averages their canonical 18-label probabilities into the fixed E41 vector, then combines E41 with E13-B's per-label family-max score vector.

Each host score row is clamped at zero for unsupported labels and normalized to sum to one. E42 uses a fixed 50/50 mean of that normalized vector and E41 probabilities. No weights are selected on V0 or V0-EXT. The notebook writes only submission.parquet, in exact test ID order.

## Deployment assets and validation

The shared dataset is zodrak/e38-e39-feature-members-v001. It contains the fitted E38 SVC bundle, the E39 CatBoost model, its tokenizer assets, the feature implementation, and offline tiktoken encoding caches. Runtime performs asset hash checks and E38/E39 probability smoke tests before checkpoint inference.

E42 uses the original E13-B v037 Kaggle checkpoint dataset and notebook implementation. Kaggle version 6 failed after all 15 checkpoint predictions because it imported `family_max_scores` from the older helper in the mounted E13-B dataset. Version 7 embeds the current score function, passed local and remote asset preflight/runtime checks, and produced a validated submission. This helper API mismatch is recorded in the repository Kaggle checklist.
