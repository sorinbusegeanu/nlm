# E24 — 30-checkpoint learned ensembles

E24 reruns E23-A/B/C with a hard cap of 30 checkpoints per outer-fold roster. Rosters are selected using only each outer training partition; inner tuning reselects from its own fitting partition. Greedy selection starts with the highest standalone balanced accuracy (except mandatory N0135/N0136 in B/C), then adds checkpoints by new correctly-covered rows with class-balanced weighting, family diversity and standalone balanced accuracy as tie-breakers.

All 2,699 V0 rows use identical E13-B prompt-group outer folds. E20's checkpoint-only candidate feature builder, CatBoost candidate scoring and Hungarian decoding are reused. E19-D and E19-F-A groups are OOF; true V0 groups are oracle-only. V0-selected checkpoint metrics make these development results, not an unbiased deployment estimate.
