# E18 — Sibling-Model Contrastive Specialists

Three prompt-matched character n-gram specialists rerank E13-B only when its selected label and strongest alternative are in the same sibling group. Matched prompt IDs are used for training pairs and fold isolation only; inference uses a response's own character-TF-IDF vector.

## Method and limits

- TF-IDF uses the existing `FoldFeatures` character view (3–5 character n-grams), fit inside each training fold.
- For each sibling pair, matched same-prompt training responses create a sparse difference vector; both orientations are used with opposite binary labels.
- GPT-5.6 Luna/Sol/Terra uses three one-vs-one contrastive classifiers. Their individual-response margins are averaged into per-model specialist scores.
- Specialist C and switch threshold are selected using nested prompt-group folds. Ordinary TF-IDF C is tuned separately on the same folds.
- E13-B is reproduced from its saved fold models and remains unchanged as the baseline.
