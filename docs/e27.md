# E27 — External Grouping and Assignment Validation

## Objective and protocol

E27 freezes the 89 probability caches and family-balanced score construction in E24 (Trust List 2 v039). Grouping is trained and selected using V2.14 prompts identified by verified `prompt_canon`; V0 labels are reserved for final classification metrics. The frozen checkpoint pool itself has historical V0 selection exposure, so its V0 results remain development evidence.

The canonical V2.14 subset contains 223,168 responses across 36,068 prompts. Rows without a non-empty `prompt_canon` are excluded from supervised grouping. Prompt groups are split deterministically, with stratification by distinct-label count, into train, validation and test partitions. Repeated responses from one label are kept as separate rows and emitted in deterministic rotation views, with at most one row per label in each view and a maximum view size of 18.

## External-to-V0 overlap check

The verified canonical V2.14 subset has 0 response-ID overlaps and 0 normalized-text overlaps with the 2,699 V0 rows (NFKC, case-folding and whitespace collapse). The exact counts are in `artifacts/analysis/e27/data_quality.json`. This establishes response-level separation; the V0 artifact does not contain canonical original prompt text for a prompt-level cross-pool identity check.

## Frozen baseline results

| Method | Accuracy | Balanced accuracy |
|---|---:|---:|
| 89-checkpoint family-balanced, independent | 62.3564% | 62.3532% |
| True V0 prompt groups + Hungarian (oracle diagnostic) | 75.6947% | 75.6858% |

The oracle row is an upper-bound diagnostic, not a deployable grouping result. Across the 25 scenarios sampling 1–10 responses per prompt, independent/oracle mean accuracy is 62.23%/66.35% (10th percentile 59.86%/64.32%, minimum 58.89%/62.89%). Across the 25 scenarios sampling 1–18, mean accuracy is 62.83%/70.88% (10th percentile 61.71%/69.82%, minimum 60.80%/68.34%). The scenario row selections are in `artifacts/analysis/e27/frozen_v0_scores.npz`; full metrics are in `frozen_roster_metrics.json`.

## Remaining evaluation

E19-F-A/B/C require external response embeddings; E19-B/D require response reconstruction and semantic embeddings. Current E19-B/D/F caches have V0-only coverage. No E27 grouping or assignment conclusions should be drawn from the oracle improvement until these external-trained groupers are fitted and evaluated on the prompt-disjoint external test partition.
