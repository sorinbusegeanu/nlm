# E26 — Ensemble Generalization and Hungarian Assignment Robustness

## Data and leakage controls

- V0 scenarios: 50 deterministic scenarios, approximately 500 responses each.
- External training rows: 502 across 77 source prompts.
- Labels represented: 15/18. Missing labels: claude-fable-5, gemini-3.7-flash, qwen3.8-max.
- V0 was reserved for evaluation; the three available base checkpoints were trained on V2.16 and selected against V0, so their outputs carry historical V0 exposure.
- The increment profile records V0 ID, normalized-text and prompt-group isolation as true; E26 independently found 0 ID, 0 normalized-text and 0 raw prompt-ID overlaps.
- No V0 prediction was substituted for an unavailable external prediction.

- External probability coverage: E22-B 3/89, E25 final rosters 3/22; remaining IDs are listed in `artifacts/analysis/e26/checkpoint_availability.csv` and were not substituted with V0 probabilities.

## Group reconstruction and interpretation

Reconstructed-pair precision: 0.8720; recall: 0.9706.
The confidence gate (0.100) was selected on an external prompt-held-out partition only.
The response-pair grouper threshold was also selected on external held-out prompts (pair F1=0.962).
The confidence gates selected externally were 0.10 for D and 0.90 for F.
Oracle Hungarian is an assignment diagnostic using the randomized scenario membership, not a deployable inference strategy.
These results compare held-out V0 scenarios as one correlated benchmark, not as 50 independent test sets.

## Recommendation

External held-out prompts select **E26-F group-aware + gated Hungarian** (balanced accuracy 0.7367). On randomized V0, the highest mean scenario accuracy is **family-balanced + reconstructed Hungarian** (0.6294; pooled balanced accuracy 0.6304).
The disagreement means there is no deployment-ready winner: only 502 meta-training rows and 15 labels were available, and all three base checkpoints were selected using V0. Treat E26-F as the externally selected research candidate and family-balanced plus reconstructed Hungarian as the V0 robustness control; validate with a larger, V0-independent checkpoint roster before deployment.

## Historical comparison

The historical E20-D result was 78.21% V0 balanced accuracy using V0-exposed E20 classifiers. E26's best pooled score on randomized V0 scenarios is 63.04% (a nominal -15.17% difference). This comparison is not apples-to-apples because the roster and decoder differ, and E20-D's result is V0-exposed. The E20-D advantage therefore does not survive as an independently validated deployment claim.

## Limitations

The external increment contains only 15 labels and source prompt groups only up to size 12. The official V0 artifact stores prompt IDs but not canonical prompt text, so exact prompt-text comparison is unavailable; the increment's upstream profile separately records accepted prompt groups as disjoint from V0. Only three V2.16-trained checkpoint probability sets were available; their outputs on the external increment were generated only after confirming no source-response overlap with V2.16. Results should be interpreted as a small external meta-training study, not a clean estimate of Kaggle generalization.
