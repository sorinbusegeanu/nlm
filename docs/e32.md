# E32 — Expand E31 from 40 to 60 checkpoints

## Accuracy on the fixed 50 `v0_group` scenarios

Both rosters were scored on the same 50 scenarios (25,000 scenario rows), using the frozen E31 deployment router for 40 checkpoints and the newly fitted E32 router for 60. The same saved E31 E19-F-A, E19-F-C, and E19-D group assignments were used for both rosters; Hungarian assignment was recomputed from each roster’s scores. Independent predictions are the router top labels. The scenarios reuse V0 responses and are a robustness diagnostic, not independent validation.

## Selection and fixed deployment

- E31’s 40 IDs are preserved as the prefix of the final roster. The remaining Trust List 2 pool had 47 eligible checkpoints. The E31 greedy selector was reused with five prompt-disjoint outer folds and four inner folds; each outer fold selected 20 additions using inner OOF balanced accuracy. A single deployment router was then fit from four-fold prompt-group OOF features over the fixed 60 IDs.
- Greedy fold-local additions were combined by the E31 consensus rule: selection frequency, mean selected rank, selected marginal BA, then checkpoint ID. The best inner-OOF roster size from 40 to 60 was **40**, at 66.6483%. The fixed 60 roster was built as requested, but selection evidence does not support expecting its larger size to improve accuracy.
- The selected 20 additions, in frozen order: `N0048, N0104, N0035, N0007, N0029, N0036, N0101, N0083, N0046, N0038, N0093, N0039, N0070, N0121, N0085, N0032, N0005, N0034, N0115, N0116`.
- Roster, checkpoint provenance, cache hashes, router fit details, router SHA-256, labels, and E31 source hashes are in [`e32_manifest.json`](../artifacts/analysis/e32/e32_manifest.json). The router is [`e32_router.cbm`](../artifacts/analysis/e32/e32_router.cbm); fold-by-fold selection is in [`selection_results.json`](../artifacts/analysis/e32/selection/selection_results.json).

## Result

The 60-checkpoint deployment underperformed the fixed 40-checkpoint E31 deployment across all four scenario means, by 0.4106 to 0.5102 percentage points. It improved fewer than half of scenarios in each configuration; E19-D improved 20 and regressed 30. The 40-checkpoint roster is therefore the stronger measured choice on this V0-derived benchmark.

No base models were trained for accuracy selection; cached Trust List 2 predictions were used. The CatBoost deployment router was fit on V0 cross-fitted features as in E31. The repeated V0-derived scenarios are correlated and are not independent evidence of Kaggle generalization.
