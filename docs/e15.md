# E15 — Logistic Correction of E13-B

E15 is a regularized binary logistic gate that may replace E13-B's selected label with its strongest alternative. It uses only cached Trust List 2 v037 checkpoint probabilities and CPU fitting (24 threads). The five outer folds are prompt-group held out; V0 remains a development set because the underlying checkpoints and trust list were selected against it. E13-B's historical Kaggle public score is 0.606; E15 was not submitted.

E13-B reproduced exactly from its saved fold models: **True**. The E13-B reference is 64.6465% balanced accuracy; E15's fold-specific C and threshold are selected using only nested prompt-group splits within the corresponding outer training partition. `Corrected` counts baseline-wrong rows fixed by E15; `Introduced` counts previously correct E13-B rows made wrong; `Wrong→wrong` counts switches that remain wrong. Correction precision is corrected / (corrected + introduced). Adjusted top-2 log loss assigns probability mass only to the E13-B label and its alternative, so it is not directly comparable with a full 18-class calibrated classifier.

E15 nets **9** additional correct rows across the five held-out folds. This is a small V0 development gain, not evidence to replace E13-B: E13-B remains unchanged as champion, and V0-based checkpoint selection means these folds do not eliminate all development-set contamination.
