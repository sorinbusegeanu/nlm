# V2.0 dataset card

## Summary

V2.0 contains **51,606 external training examples**, balanced at **2,867 per class** across 18 competition labels. Sampling seed: **2026**. It uses no training or inference.

The available V1.3 source rows are included through the normalized V1.3 build output. Open Pool and B2M are ingested from their raw public tables. Rows not already present in V1 were prioritized. If a class did not have enough unique eligible external rows, rows already present in V1 could fill the quota; these are counted below and retain their best external provenance.

## Cleaning and leakage controls

Rows outside **50–2000 characters** were removed. Only competition labels with nonempty source dataset, source file, license and prompt-group provenance are retained. English is taken from trusted English metadata when available and otherwise detected; unknown/non-English rows are removed. Explicit code blocks/programming outputs, reasoning or serialized conversation/tool traces, truncation markers/metadata, exact duplicate responses, cross-label response conflicts, exact V0 response matches and exact V0 prompt-ID matches are excluded.

The full V0 reference was checked: **2,699 rows**, spanning 150 prompt IDs. The official V0 files contain prompt IDs but no prompt text. Therefore exact ID overlap is checked, but semantic prompt-text overlap cannot be independently certified; this limitation is recorded in the profile. The response-overlap check covers all V0 rows, not only its validation split.

## Audit and source availability

The profile records original candidate row counts, retained counts per source and label, each removal reason, source hashes, class balance, source diversity and V1 reuse. Exact duplicates are normalized with NFKC, case folding and whitespace collapse. Deterministic selection favors examples not present in V1 and spreads selections across sources and prompt groups. Selected GLM source IDs were checked against raw turn metadata; 0 selected multi-turn rows were found.

All primary GLM and GPT V1.3 raw files were normalized temporarily for this build without the older 1,900-character cap, so V2.0 applies its own 2,000-character rule. The separate `gemini37_unverified.parquet` collection was audited but excluded because its model attribution is explicitly unverified. The indexed Claude Opus 4.8 collection was unavailable locally (download manifest records a 404), so it contributed no rows.

No model training, checkpoint modification or inference was performed.
